# Localização

Na tela de nova memória, toque em **Usar minha localização** para preencher latitude e longitude. A localização só é solicitada depois desse toque. Também é possível preencher as coordenadas manualmente ou deixar os campos vazios.

O app pede permissão para acessar a localização durante o uso. Se ela for negada ou não houver uma posição disponível, a memória ainda pode ser salva sem localização.

Android e Web são compatíveis. A execução no iOS precisa ser conferida em um Mac com Xcode.
